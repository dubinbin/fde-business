# 2026-09-21

## 制造业 FDE 场景实验室（React + TS + Tailwind 网站）

- 从零搭建于工作区根目录：`package.json` / `vite.config.ts` / `tailwind.config.js` / `src/`。
- 结构：`src/data/scenarios.ts`（9 个场景元数据，集中配置）、`src/data/quote.ts`（报价演示模拟数据，含 `DEMO_TODAY='2026-09-21'` 基准日）、`src/lib/money.ts`（金额舍入）、`src/lib/quote.ts`（报价计算引擎）、`src/lib/nlp.ts`（有限规则 NL 解析）、`src/components/`（Nav/Footer/ui/DemoShell/Preview/ScenarioCard）、`src/demos/`（9 个交互演示）、`src/pages/`（Home / ScenarioDetail）。
- 关键约定：金额只在展示环节四舍五入，聚合值由「已舍入明细」相加，保证明细与合计一致；缺价显示待确认不按 0；所有状态确定性、无随机。
- 踩坑：`BomDiffDemo` 中模块级 `let seq` 声明在调用它的常量数组之后，打包后触发 TDZ 运行时错误（SSR 测试暴露不出来，只有浏览器测试能发现）。教训：模块级可变状态必须放在文件最顶部。
- 报价单口径：含税金额 = 含税单价 × 数量，税额 = 含税 − 未税（这样报价单上单价×数量=金额）。
- 验证链路：`scripts/check.ts`（数值一致性，esbuild 打包后 node 运行）、`scripts/smoke.tsx`（react-dom/server SSR 渲染检查）、`scripts/e2e.cjs`（playwright + 本机 Chrome `channel:'chrome'`，34 项交互断言）、`scripts/build-standalone.mjs`（生成双击可开的单文件 `standalone.html`，因为 file:// 无法加载 ES module）。
- 本机 playwright 浏览器版本与 npm 包不匹配时，用 `chromium.launch({ channel: 'chrome' })` 直接用系统 Chrome。
